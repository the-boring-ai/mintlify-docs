## Choose the right surface

Use the SDK in the browser. It installs Bily and sends page, commerce, and custom events.

Use the API on your server. It authenticates your backend, respects organization and store boundaries, and exposes Bily data and supported actions.

Use MCP in a compatible AI client. It discovers the current operation catalog and runs scoped work through two stable tools.

All three share the same Bily data and activation layer. You can evolve Bily Apps without replacing the website integration.

## Let the SDK handle the details

- Preserves the exact tracking URL and every query parameter you copy from Bily.
- Queues calls safely while Bily loads.
- Generates an event ID and timestamp when you do not provide them.
- Autocompletes known Bily events while accepting your own event names.
- Imports safely during server rendering.
