Start with `search`. Then pass one focused async arrow function to `execute`.

For campaign and creative actions, follow the [reviewed Ads draft workflow](/rest-api/ads). Save and review first, publish separately, then poll the durable job and verify each result.

## Find your identity and stores

Search input:

```json
{
  "query": "show the authenticated identity, organizations, and stores",
  "limit": 6
}
```

Execution code:

```javascript
async () => {
  return bily.context();
}
```

The result contains `user` and `organizations[]`. Accessible stores appear under each organization.

A standard store-scoped fallback key needs no organization input.

With Bily Connect, add `organizationId` to `execute` only when the user explicitly selects one accessible organization:

```json
{
  "organizationId": "org_01J8W7T9G3E6ZQ4M2K5N8P1R0S",
  "code": "async () => bily.context()"
}
```

## Explain a revenue change

Search for the right comparison operation:

```json
{
  "query": "compare revenue to the preceding period and explain traffic, conversion, and order value",
  "storeUrl": "store.example.com",
  "limit": 5
}
```

Run the returned revenue-trend helper with real calendar dates:

```javascript
async () => {
  return bily.analytics.getRevenueTrend({
    storeUrl: "store.example.com",
    filters: {
      startDate: "2026-07-01",
      endDate: "2026-07-07",
    },
    comparisonFilters: {
      startDate: "2026-06-24",
      endDate: "2026-06-30",
    },
  });
}
```

Review the returned readiness, warning, and sample-size fields before making a business recommendation.

## See which analytics data is available

```javascript
async () => {
  const datasets = await bily.analytics.listDatasets({
    storeUrl: "store.example.com",
  });

  console.log("Catalog loaded");
  return datasets;
}
```

The returned data appears in `result`. The message appears in `logs`.

The generic SQL catalog currently contains only Shopify `customer_ltv` and `cohorts` datasets. Websites return an empty catalog. Use the dedicated analytics helpers, such as `getRevenueTrend`, for website and advertising metrics.

## Complete and verify a supported action

For a request such as refreshing connected advertising accounts, follow this sequence:

1. Call `search` with the exact intent and store.
2. Review `riskTier`, `approvalPolicy`, preconditions, and verification guidance.
3. Show the proposed function to the user.
4. Get explicit approval in the client.
5. Run one focused action, then verify it with a read.

```javascript
async () => {
  const refresh = await bily.actions.syncAdAccounts({
    storeUrl: "store.example.com",
  });

  const accounts = await bily.getManagedAdAccounts({
    storeUrl: "store.example.com",
  });

  return { refresh, accounts };
}
```

Do not add other writes to the function without showing them. If the request expands, present the complete function for approval again.

## Preview the pending saved-image request flow

The accepted-first helper family is a pending contract, not a claim of current availability. Once the deployed catalog supports it, use the [source-filtered read](/rest-api/creative-generation#check-unresolved-work-and-availability-first) to recover unresolved work and inspect current admission before preparing a fresh request.

Keep the client’s single-send lock across that read. Preserve any existing ID or unknown key first. Only after explicit generation approval and verified current availability may the caller persist a fresh prefixed key and send one `requestStatic` call. The helper must receive that saved key unchanged. A lost response means same-key `findGenerationRequest` recovery, followed by `getGenerationRequest` and the linked `getGenerated` read; it does not authorize another POST.

Dedicated Demand Gen IMAGE read/edit helpers are also pending. Read the exact advertiser selection and current fingerprint, save a reviewed paused action draft, publish separately, and verify it. They do not upload a generated image or clone an arbitrary source ad. See [the bounded image profile](/rest-api/ads#pending-demand-gen-image-child-operations).
