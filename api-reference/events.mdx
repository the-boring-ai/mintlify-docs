`BilyEvent` provides autocomplete for known events while accepting any custom string.

```typescript
type BilyEvent = KnownBilyEvent | (string & Record<never, never>);
```

Event names are case-sensitive. Prefer the exact capitalization below for Bily events and stable snake_case for application events.

## Preferred ecommerce names

For new ecommerce tracking, use the current names in the [ecommerce guide](/guides/ecommerce). The SDK accepts these compatibility names and normalizes them before delivery:

| Compatibility name | Current name |
| --- | --- |
| `Pageview` | `PageView` |
| `Add to Wishlist` | `Product Added to Wishlist` |
| `Category Viewed` | `ViewCategory` |
| `Contact Form Submitted` | `Contact` |
| `New Customer Order` | `New Customer Purchase` |
| `Payment Add Address Info` | `Checkout Address Info Submitted` |
| `Payment Add Contact Info` | `AddContactInfo` |
| `Payment Add Shipping Info` | `AddShippingInfo` |
| `Product Added To Wishlist` | `Product Added to Wishlist` |
| `Remove from Cart` | `Product Removed From Cart` |
| `Remove from Wishlist` | `Product Removed From Wishlist` |
| `Search` | `Products Searched` |

## Custom application events

```typescript
track("workspace_created", {
  workspace_id: "workspace_456",
});
```

Custom event names must contain at least one non-whitespace character. Keep a small internal event catalog so spelling does not drift across components.
