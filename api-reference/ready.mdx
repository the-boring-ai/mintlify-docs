title: "ready()"

---

Use `ready()` when you need to confirm that the Bily browser runtime initialized. Normal event tracking does not wait for it because `track()` queues early calls.

## Check readiness

```typescript
function ready(): Promise<void>;
```

## Verify the installation

In the browser, call `init()` before awaiting `ready()`.

```typescript
import { init, ready } from "@bilyai/js";

init({
  scriptUrl: "https://tracking.example.com/b.js?shop=store.example.com",
  loadTimeoutMs: 15_000,
});

try {
  await ready();
  console.info("Bily is ready");
} catch (error) {
  console.error("Bily failed to load", error);
}
```

## Know when it resolves

In 2.0.8, the promise resolves after the browser runtime finishes initialization and can accept queued events, not merely when its bootstrap script loads or exposes a queue. Queued events wait for that runtime handoff. Readiness is not a delivery receipt from an analytics destination. During server rendering, it resolves immediately because there is no browser script to load.

## Handle a rejection

The promise rejects when:

- The browser reports a script load error.
- Bily does not finish runtime initialization before `loadTimeoutMs`, even if the bootstrap script loaded.
- The script loads but does not expose a usable Bily browser API.
- The configured tracking URL conflicts with an existing script or runtime ownership.

The default timeout is 15 seconds. Set a value from 1 to 60 seconds through `init()`.

## Retry one failed load

For a recoverable network or script-load failure, retry once with the same exact tracking URL, then call `ready()` for the new attempt.

A script or runtime ownership conflict requires a different recovery: resolve the duplicate installation or conflicting URL, then reload the page. Calling `init()` again does not clear an ownership conflict. Never bypass these guards or switch tracking URLs within the same page.

Use this bounded retry only after identifying a recoverable load failure; it does not repair ownership conflicts.

```typescript
async function loadBily() {
  const options = {
    scriptUrl: "https://tracking.example.com/b.js?shop=store.example.com",
  } as const;

  init(options);

  try {
    await ready();
  } catch {
    init(options);
    await ready();
  }
}
```

If production keeps failing, check the URL, network policy, and duplicate installation. Do not retry indefinitely.
