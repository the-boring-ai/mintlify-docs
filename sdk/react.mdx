---
title: "React Router"
description: "Add Bily to React and track each route without duplicating page views."
---

Add one Bily component inside your existing React Router. It starts the SDK once; the browser script owns page-view tracking.

Do not add a raw Bily script tag anywhere else in the application. `init()` loads the script for you.

## Install Bily

```bash
npm install @bilyai/js
```

## Track every route once

The browser script records the initial page and supported client-side navigation automatically. Do not add manual `PageView` calls for those navigations; use `track()` for business events.

```tsx src/bily-tracking.tsx
import { useEffect } from "react";
import { init } from "@bilyai/js";

const BILY_SCRIPT_URL =
  "https://tracking.example.com/b.js?shop=store.example.com";

export function BilyTracking() {
  useEffect(() => {
    init({ scriptUrl: BILY_SCRIPT_URL });
  }, []);

  return null;
}
```

Mount the component once in a component that your existing router already renders. Keep your existing router and application shell.

```tsx src/AppRoutes.tsx
import { BilyTracking } from "./bily-tracking";

export function AppRoutes() {
  return (
    <>
      <BilyTracking />
      {/* Keep your existing routes and application UI here. */}
    </>
  );
}
```

This setup expects `react-router-dom` to be installed and a router to exist above `AppRoutes`. Do not add another `BrowserRouter`, `Router`, or `RouterProvider`.

Repeated `init()` calls with the same URL are safe. One component keeps loader ownership clear.

## Track successful actions

Call `track()` only after the user action succeeds.

```tsx src/LaunchCampaignButton.tsx
import { track } from "@bilyai/js";

export function LaunchCampaignButton({ campaignId }: { campaignId: string }) {
  async function handleClick() {
    await launchCampaign(campaignId);
    track("campaign_launched", { campaign_id: campaignId });
  }

  return <button onClick={handleClick}>Launch campaign</button>;
}
```
